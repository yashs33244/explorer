# 2. Light pages, wide figures, highlighted tables

Status: accepted (2026-10)

Artifact pages are light only. Figures run up to 1180px wide, and repo maps and dense architecture use a "bleed" size that takes nearly the whole window. Tables mark their deciding column and rows, and every table with 6 or more rows gets a filter box and sorting.

Why: readers skim. A narrow column shrinks diagram text below reading size, and an unmarked table hides the answer among the rows.

Cost: bleed figures need a 1200 to 1400 wide viewBox to stay legible, and every interactive feature must leave the static page complete.
