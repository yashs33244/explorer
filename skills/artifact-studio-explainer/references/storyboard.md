# Storyboard reference

Manim engine (the default): the storyboard format, layouts and build actions are in `../manim/GUIDE.md`. A working example is `../manim/examples/demo/storyboard.json`.

Studio engine (optional): its storyboard guide lives in daybook reel, at `$DAYBOOK_REEL/src/studio/storyboard-guide.md`, and is not part of this repo.
